# HAR Analysis 📊  
*Analyzing Human Activity Recognition Data Using Machine Learning and Deep Learning Models*

---

## 📖 Overview
This repository focuses on **Human Activity Recognition (HAR)** using data analysis and predictive modeling. The project demonstrates the application of machine learning and deep learning techniques to classify and predict human activities based on sensor data.

---

## 🚀 Features
- **Comprehensive Preprocessing**: Techniques like missing value imputation, scaling, and feature extraction.
- **Modeling Techniques**: 
  - Traditional ML models (Logistic Regression, Random Forest, SVM)
  - Advanced DL models (CNN, LSTM, GRU)
- **Visualization**: PCA, t-SNE, Confusion Matrix, Accuracy/Loss curves.
- **Performance Metrics**: Accuracy, Precision, Recall, F1-score, AUC.

---

## 📊 Dataset
The dataset used in this analysis contains sensor data from wearable devices to track various human activities.  
**Source**: [Dataset Link](https://www.kaggle.com/datasets/sayeedzaman016/humanactivityrecognitiondataset)
**Features**:
- Accelerometer and gyroscope readings.
- Labels for activities like walking, standing, sitting, etc.

## 🛠️ How to Use
1. Clone the repository:
   ```bash
   git clone https://github.com/sayeedzaman/HAR-Analysis.git
   ```
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the Jupyter notebooks for step-by-step implementation:
   ```bash
   jupyter notebook
   ```
4. Execute the scripts for quick predictions or data preprocessing:
   ```bash
   python scripts/preprocess_data.py
   python scripts/predict.py
   ```
